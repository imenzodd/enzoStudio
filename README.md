# Enzo Studio

A responsive, single-page image-to-ASCII art website. No backend or build step is required.

## Run locally
Open `index.html` in a modern browser. For best results, use a local static server or deploy it to GitHub Pages.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `enzo-studio`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for the Pages URL to appear in the Pages section.

## Features
- Image upload and drag-and-drop
- Adjustable character density and contrast
- Multiple character sets
- Monochrome, original color, and terminal-green modes
- Invert brightness and glow options
- Export as PNG or plain text; copy ASCII to clipboard
- Responsive layout for desktop and mobile
- Images are processed locally in the browser

## Notes
The interface uses Google Fonts when online, with generic monospace/sans-serif fallbacks. No framework, build tooling, or API key is needed.
